# Chrome Web Store listing text

## Summary

Open source currency converter with private local processing and daily ECB rates. No tracking, ads, or API key.

## Description

A straightforward, open-source currency converter that respects your privacy.

**What it does**

- **Hybrid mode:** Automatically converts recognized prices on webpages and also provides selection tooltips.
- **Interactive mode:** Leaves the page unchanged and shows a conversion when you select a price.
- **Smart detection:** Handles currency symbols, codes, names, ambiguous symbols, negative amounts, compact values, and regional number formats.
- **Modern page support:** Converts prices in embedded frames, dynamic content, and open shadow roots.
- **Flexible display:** Lets you choose the target currency, source-format rules, output formatting, and defaults for ambiguous symbols.
- **Accessible motion:** Includes an option to disable extension animations.

**Why this extension?**

- **100% open source:** The full implementation can be inspected.
- **Privacy first:** Page text is processed locally. There is no analytics or tracking.
- **Reliable rates:** Uses daily public exchange rates from the European Central Bank and keeps a local cache for offline use.
- **No bloat:** No ads, paywalls, remote code, or unnecessary account.
